# EXCELLENT TUTORAT — Prototype Web

Prototype front-end (HTML/CSS/JS) d'un site de tutorat avec :

- Connexion Google (démo UX prête à brancher avec OAuth réel)
- Gestion des rôles (admin, enseignant, élève, parent)
- Calendrier intelligent avec permissions
- Paiement avant programmation des séances
- Réservation d'une séance d'essai gratuite (1 fois par élève)
- Pages clés : accueil, services, tarifs, essai, connexion, dashboards, calendrier, paiement, contact

## Démarrage

```bash
python -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.
